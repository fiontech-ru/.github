Практическая песочница и рабочие инструменты: инфраструктура как код, автоматизация развёртывания, мониторинг и эксплуатация.

## 🎯 Что здесь
Этот аккаунт — дополнение к моему основному профилю. Здесь я выкладываю:
- **Скрипты эксплуатации** — диагностика Docker, обслуживание серверов, ротация логов
- **IaC** — Terraform/Ansible модули для типовых задач
- **CI/CD** — примеры пайплайнов (GitHub Actions, GitLab CI)
- **Учебные заметки** — конспекты по Kubernetes, сетям, Linux
